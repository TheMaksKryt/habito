## Мажоры и что в них важно

- **ioredis 6** — по умолчанию RESP3 (нужен Redis 6+, у нас 8). Опции
  `enableOfflineQueue`/`maxRetriesPerRequest` не менялись; проверено живым
  `/health`: 200 с Redis, 503 за единицы миллисекунд без него.
- **Vitest 5** — `clearMocks` теперь `true`, `vi.mock` внутри функций
  бросает ошибку, Vite ≥ 6.4 (в lock — 8.x). Smoke-тест web проходит без
  правок.
- **happy-dom 21** — загрузка CSS и iframe выключена по умолчанию (защита от
  SSRF); на тесты не влияет.
- **Postgres 18** — изменился каталог данных, том монтируется в
  `/var/lib/postgresql` (см. CLAUDE.md). Данных и миграций ещё не было, dev-том
  пересоздан.

## Что сознательно не взято

- **TypeScript 7.0.2** — typescript-eslint 8.72 требует TS `< 6.1`, vue-tsc
  ждёт TS 7.1. Это ровно критерии раздела «Политика версий TypeScript»
  конституции; остаёмся на `^6`. Вернуться, когда оба условия выполнятся.
- **Prisma 8** — только release candidate (8.0.0-rc). Взять после стабильного
  релиза отдельным изменением: там смена поиска конфига (`prisma7.config.*`)
  и маппинга ошибок адаптера.
- **Postgres 19** — beta.
- **@hey-api/openapi-ts** — 0.99.0 уже последняя; патч `@ts-nocheck` остаётся,
  две ошибки на TS 6.0.3 + vue-tsc 3.3.13.

## Побочные находки

- Nuxt 4.6 добавляет Volar-плагин `vue-router/volar/sfc-route-blocks` в
  tsconfig; при isolated-линкере Bun он резолвится только если `vue-router` —
  прямая зависимость web. Добавлен как зависимость (правило в CLAUDE.md).
